PaperTrail

Start from the papers you trust. Find the ones you missed, with receipts.

A Zettlr-style research workspace on the web. A researcher brings a question and a few trusted papers; PaperTrail finds the papers they connect to, ranks them in honest lanes, checks every quoted claim against the source, and turns the keepers into linked Markdown notes and a graph.

04 · Evidence · measured today

Why the ranking is built on seed links

Hold-out test: take a real review, keep 5 of its references as seeds, hide the rest, and check what each route finds and how each ranking orders it. Two reviews, so read these as a direction, not a benchmark. Scripts in eval/.

What this changed: OpenAlex related_works is dropped (0 hits twice); seed links lead the ranking; any text signal earns weight only after the harness shows it helps (title text dragged every blend down). The real run added three rules: generic tool papers top the Linked lane until the judge's facets and the Lens sort them; a seed can't cite a paper published after it (OpenAlex has such errors), so links get a date check; Fresh papers only come from query expansion and the Scout.

13 · Deploy to Nebius

Three deploys, each a new endpoint

Creating an endpoint takes about 5 minutes and there is no update command. The UI endpoint is public: a browser can't send a Bearer header when it opens a page.

# 1. CLI + sign-in
curl -sSL https://artifacts.nebius.cloud/cli/install.sh | bash
nebius profile create
# 2. Registry
export REGISTRY_PATH=$(nebius registry create --name papertrail \
  --format json | jq -r ".metadata.id" | cut -d- -f 2)
nebius registry configure-helper
# 3. Build and push (amd64 is required on a Mac)
docker buildx build --platform linux/amd64 \
  -t cr.<region>.nebius.cloud/$REGISTRY_PATH/papertrail:v1 --push .
# 4. Endpoint (no --auth = public)
nebius ai endpoint create --name papertrail-v1 \
  --image cr.<region>.nebius.cloud/$REGISTRY_PATH/papertrail:v1 \
  --platform cpu-d3 --preset 2vcpu-8gb --container-port 3000 \
  --disk-size 20Gi --subnet-id <subnet-id> \
  --env TOKEN_FACTORY_API_KEY=…,TAVILY_API_KEY=…,OPENALEX_API_KEY=…,OPENALEX_MAILTO=…
# 5. Public URL
nebius ai endpoint get $ID --format json \
  | jq -r '.status.public_endpoints[] | select(startswith("https://"))'
