## Also likely (short answers)

- **Where does my data go?** The notes you build from go to the local server; model calls go to Token Factory; search queries go to OpenAlex, PubMed, arXiv and Tavily. Notes stay in the browser vault; the library and per-paper JSON files are on this laptop under `data/library/<libraryId>/`.
- **Can I see exactly what was called?** Yes. Every source call, model call and Tavily call is traced under `logs/runs/<libraryId>/` with a summary of goals, per-source counts and the top papers with every component.
- **Do generic tool papers flood the list?** The label `method/tool` is attached and the chat can filter or reweight; a paper's relevance is embedding similarity to the question and subtopics, not citations.
- **Is the citation data reliable?** Not always: OpenAlex listed a 2017 review as cited by a 2016 seed in the earlier pipeline. Each score row shows its source link so you can check. (RANKING_AND_STORAGE 1.4)
- **Why is a paper high with zero citations?** Citations are one component (18% by default); papers under two years old use FWCI or a neutral 0.5, and the report card says which.
- **Does the graph show citations between papers?** Yes. The demo graph shows 60 papers and 287 citation links (measured in the browser on main ba70395). In a real library, graph.json has 1,296 edges, 1,112 of them between two library papers (lib_20261018141959_87bff3, recomputed from its papers).
- **What if OpenAlex has no references or the daily budget is spent?** Europe PMC fills in the references: in a caffeine build with OpenAlex switched off it added 227 citation links, and the reference step took 9.1 s (lib_20261018144844_4cda2c, as reported by the captain). An OpenAlex entity cache also keeps builds working: it holds 12,416 distinct entities (works, authors, sources) and the backfill processed 41,479 entity records from 1,013 cached responses (counts taken 2026-10-18 15:14 UTC).
- **How do I see why a paper has its score?** The report card shows a score donut and value bars: where the points come from, row by row, with evidence under each row. This is a view of the same numbers, not a different score.
- **Does it scale to all of PubMed?** We do not index PubMed. We build a pile per question (cap 600 by default), so the work grows with the pile.
